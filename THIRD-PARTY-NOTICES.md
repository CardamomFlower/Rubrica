## feTurbulence reference code (textures)

The leather and paper grain is generated by a C# port of the reference implementation
of the `feTurbulence` filter printed in the W3C SVG 1.1 specification
(https://www.w3.org/TR/SVG11/filters.html#feTurbulenceElement), itself based on Ken
Perlin's noise function. Copyright (c) W3C (MIT, ERCIM, Keio, Beihang).
